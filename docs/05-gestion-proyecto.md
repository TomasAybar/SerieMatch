# Gestión del Proyecto

## Metodología
Vamos a trabajar de forma ágil, usando un tablero en Trello para organizar las tareas.

## Roles
- Todos los integrantes participan en el desarrollo y la documentación.
- Proponemos, editamos y corroboramos cada parte realizada por cada integrante.

## Herramientas
- **Trello**: para gestionar las tareas y el avance del proyecto.
- **GitHub**: para el control de versiones del código.
- **Discord**: para la comunicación del grupo.

## Organización de tareas
En el tablero de Trello vamos a manejar las siguientes listas:
- Por hacer
- En progreso
- En revisión
- Hecho

Cada tarea se carga como una tarjeta y se va moviendo según el avance.

## Seguimiento
Nos reunimos periódicamente (por Discord) para revisar el progreso y ajustar las tareas si es necesario.
